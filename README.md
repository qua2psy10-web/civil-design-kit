# 土木設計室

逆T型・L型擁壁の常時外的安定と、矩形直接基礎の支持力・偏心の概略照査。日本語・ブラウザ内計算。

## 使い方

`起動.command` をダブルクリック後、表示された http://127.0.0.1:4173 を開いてください。
Python 3が必要です。停止はターミナルで Ctrl+C。
`dist/index.html` を直接開くこともできますが、保存データはブラウザのファイルURLの扱いに依存します。継続利用にはHTTP経由を推奨します。

1. 検討名を入力し、形状・寸法、土質・荷重、基礎地盤、判定基準を設定。
2. 計算結果タブで全計算値・重量重心を確認。計算根拠タブで式・適用範囲を確認。
3. 「条件を保存」で入力と基準を複製保存。左欄で再利用。条件比較で保存案との差を確認。
4. CSVはUTF-8 BOM付き。PDF出力は印刷ダイアログで「PDFとして保存」。
5. 保存先はこの端末・ブラウザのlocalStorage。共有・端末移行にはJSONバックアップを使用。

## モデルと制限

等厚鉛直竪壁・矩形底版・かかと版あり。Hは底版上面から竪壁天端、t1は竪壁厚、Bは底版全幅、t2は底版厚、Bfは前端から竪壁前面、Dは底版下面から前面地表まで（0〜t2）、Hbは背面盛土の上昇高上限。
かかと上の盛土は勾配βからHbで水平に打ち切る形状。土圧面はかかと端の仮想鉛直背面。Coulomb式のδはこの仮想背面の摩擦角。盛土打切りによる土圧低減は行わない。
背面土cは入力記録するが土圧低減には使わない。基礎支持力には独立したφf・cf・γfを使用。支持力はVesic帯基礎式の傾斜荷重簡易モデル。支持力需要はV/B_effでありqmaxとは異なる。
前面受働抵抗・底面粘着・上載荷重による有利な鉛直力は不算入。
地震、水圧、全体すべり、斜面上基礎、沈下、部材設計は対象外。
初期安全率は仮設定。特定の国内基準への適合を表明するものではない。実施設計への適用には地盤調査・採用基準との照合が必要。

## 直接基礎の支持力・偏心照査

左の「杭・基礎」から開きます。基礎底面中心に換算した圧縮鉛直力と二方向の曲げ、地盤資料に基づく許容総接地圧を入力してください。偏心指標が1以下の場合は、線形分布で四隅の接地圧を算定し、最大値を許容値と比較します。部分接地の場合は支持力を未判定とします。サンプルの許容値は案件の条件に置き換えてください。

検討名・許容値の出典・入力をブラウザに保存し、保存条件と比較できます。CSVには入力、計算式、結果を含めます。PDFはブラウザの印刷画面から保存します。

## 排水の流下能力照査

左の「排水」で矩形側溝・円管（部分充満）を選択します。合理式 Qp=C i Ac/360（Acはha、iはmm/h）と、Manning式 Qc=A R^(2/3) I^(1/2)/n を使用します。流速と余裕高は指定した照査水深で算定します。計画流量に対応する水深の逆算は行いません。

降雨強度は採用確率年・流達時間に対応する値を入力し、粗度係数・流速上下限・必要余裕高は案件の採用基準に合わせてください。条件と出典をブラウザ内に保存し、再利用・比較・CSV・PDF印刷が可能です。定常等流・単一断面の概略照査で、背水・水路網・入口損失・圧力流は対象外です。

計算の検証は `node --experimental-strip-types tests/drainage.test.ts` で実行します。合理式の単位換算、矩形断面、半充満円管、無効入力、各NG状態を確認します。

## ソース構造

- `lib/retaining.ts`：純粋な計算関数、入力定義、判定基準初期値、計算式。
- `lib/modules.ts`：将来モジュールの登録定義。排水、調整池は準備中。
- `lib/foundation.ts` と `app/foundation.tsx`：矩形直接基礎の計算と入力・比較・出力。
- `app/page.tsx`：入力・保存・比較・出力UI。
- `app/globals.css`：レスポンシブ画面とA4印刷用スタイル。
- 保存スキーマ：civil-cases-v1 / ケースID・名称・日時・入力値と基準・計算エンジン版。

計算方式を変更する場合はengineVersionを更新し、保存スキーマ移行を検討。追加モジュールには独立した入力定義と計算関数・照査結果を追加する。
